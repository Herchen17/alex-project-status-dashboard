#### **SOLDIER-OP-002**: Evaluation Framework Creation  
**Objective**: Create systematic scoring system for opportunity assessment
**Criteria Framework**:

**Build Complexity Assessment (1-10 scale)**:
- Technical complexity (simple web app vs complex AI system)
- Time to MVP (days vs months)
- Required skills alignment with our capabilities
- Infrastructure requirements
- Third-party dependencies

**Profit Potential Assessment (1-10 scale)**:
- Market size indicators
- Revenue model clarity  
- Competition density
- Monetization timeline
- Scalability potential

**Autonomous Build Score (1-10 scale)**:
- Can be built with current AI capabilities
- Minimal human intervention required
- Clear technical requirements
- Automation-friendly business model
- Low ongoing maintenance

**Final Opportunity Score**: (Build Complexity × 0.3) + (Profit Potential × 0.4) + (Autonomous Score × 0.3)

**Model Selection**: Opus (strategic framework creation - high stakes, novel problem)
**Deliverables**: 
- Scoring algorithm
- Evaluation criteria documentation
- Assessment templates
