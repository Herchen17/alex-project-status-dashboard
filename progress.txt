# Project Status Dashboard Progress Log

## Project Overview
Create a simple project status dashboard with HTML/CSS/JS that shows completion percentages for Alex's portfolio projects.

## Codebase Patterns
- Each project lives in /projects/{project-name}/ directory
- Standard structure: README.md + index.html + supporting files + data.js
- HTML follows system font pattern: -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif
- Color scheme: background #fafbfc, text #172b4d, accent #0052cc
- Clean, professional styling with subtle shadows and borders
- Responsive design with CSS Grid for layout
- Tests in /test/ directory using Node.js assert and jsdom for HTML validation
- **Data Model Pattern:** Class-based validation with constructor validation, status colors, utility functions
- **Test Pattern:** Comprehensive coverage with custom describe/it test runner, mock data validation
- **Validation Pattern:** Throw errors for invalid data, provide detailed error messages with context
- **Schema Pattern:** JSON Schema Draft 7 for standardized data structure, comprehensive field validation, enum constraints
- **Testing Schema Pattern:** Structural validation, edge case testing, pattern matching validation
