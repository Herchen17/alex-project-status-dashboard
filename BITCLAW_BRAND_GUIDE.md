# BitClaw Brand Guidelines

## Logo Assets

### Logo Variations Needed
- **Large (1024x1024):** Social media profile images, website headers
- **Medium (512x512):** Documentation, presentations
- **Small (128x128):** App icons, favicons
- **Square (200x200):** Token listing thumbnails
- **Wide (800x400):** Banner formats, social covers
- **Monochrome:** Black & white versions for print
- **Transparent PNG:** Overlays and flexible backgrounds

## Color Palette
**Primary:** 
- Orange/Copper: #FF6600, #CC5200
- Bitcoin Gold: #F7931A
- Dark Background: #1A1A1A, #2D2D2D

**Accent Colors:**
- Circuit Blue: #00BFFF
- Metal Silver: #C0C0C0
- Warning Red: #FF3333

## Typography
**Headers:** Bold, technical sans-serif (Arial Black, Roboto Bold)
**Body:** Clean sans-serif (Arial, Roboto)
**Code/Technical:** Monospace (Courier New, Source Code Pro)

## Visual Elements
- **Robotic claw:** Strength, precision, autonomy
- **Bitcoin symbol:** Proven monetary mechanics
- **Circuit patterns:** Digital native, tech infrastructure
- **Geometric design:** Professional, engineered feel

## Usage Guidelines
- Never distort logo proportions
- Maintain clear space around logo (minimum 1/4 logo width)
- Use high contrast backgrounds
- Avoid placing on busy backgrounds without backdrop

## Applications
- Token contract metadata
- Social media profiles (Twitter, Discord, Telegram)
- Documentation headers
- Exchange listing assets
- Marketing materials
- Website/landing page assets
